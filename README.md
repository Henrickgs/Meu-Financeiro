# Meu Controle Financeiro

Planilha de controle financeiro pessoal desenvolvida em Excel, com dashboard, fluxo de caixa e acompanhamento de receitas e despesas.

## Recursos

- Dashboard com indicadores financeiros e gráficos.
- Registro de receitas e despesas previstas e realizadas.
- Resumo mensal e anual.
- Fluxo de caixa por categoria.
- Cadastro de contas e cálculo de saldos.
- Categorias e meses configuráveis.

## Como utilizar

1. Baixe o arquivo `controle_financeiro_pessoal_moderno.xlsx`.
2. Abra no Microsoft Excel ou em um aplicativo compatível.
3. Na aba **LANÇAMENTOS**, substitua os dados de exemplo pelos seus lançamentos.
4. Na aba **CONTAS**, ajuste os nomes das contas e os saldos iniciais.
5. Consulte o **DASHBOARD** e o **FLUXO DE CAIXA** para acompanhar os resultados.

## Estrutura

- `controle_financeiro_pessoal_moderno.xlsx` — planilha principal.
- `README.md` — documentação do projeto.

## Observação

Os dados de exemplo são fictícios. Remova-os antes de utilizar a planilha com seus dados reais.
